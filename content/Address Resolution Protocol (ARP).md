The *Address Resolution Protocol* helps determining the network interface's [[MAC Address]] through it's *IP Address*. 

### ARP Table 
Each node on a [[Local Area Network]] has a table which contains IP Address/[[MAC Address]] mappings for some nodes. 

Maintains it with some *TTL (Time to Live)* which means that the mapping will be forgotten after some time.
