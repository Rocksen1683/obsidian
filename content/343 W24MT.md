### Question 1 
(a)
Two approaches that simulate non-local transfer are *global flags*, *tagged union*, *variants*.

(b)
- Tagged unions bundle an erroneous return and a valid return into a union with a tag which can be checked to discriminate upon receiving the returned value
- A global status flag is a shared flag which is set to an error code to communicate exceptional behaviour (c)

c) These approaches are not truly achieving non-local transfer as they don't have the ability to jump down the call stack to an arbitrary stack frame below them. They simulate it by passing information down the call stack.
