A *proxy server* is an *intermediary router* for requests which relays requests to another server and gets the response relayed back. 

### [[Load Balancer]]

A *cache* is a small data storage structure designed to improve performance when accessing a large data store. 

The cache stores the *most recently* or *most frequently* accessed data. As it's small the cache can be accessed more quickly than the main data store.
