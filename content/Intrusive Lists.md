*Intrusive Lists* are non-contiguous variable length data structures

![[Pasted image 20241208131324.png]]


- `uColable` is a *singly linked* intrusive list object
- `uSeqable` is a *doubly linked* intrusive link object
![[Pasted image 20241208132754.png]]

- `uQueue` and `uStack` uses `uColable` and are singly linked
- `uSequence` uses `uSeqable` and are doubly linked
