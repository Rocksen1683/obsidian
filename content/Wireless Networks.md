The two main challenges of a *wireless network* are:
1. transmission of data over a *wireless link*
2. handling a mobile user who changes point of connection to network 

### Elements of Wireless Networks
![[Pasted image 20241205174722.png]]
- *Wireless Hosts*: laptops, smartphones that run applications and may or may not be mobile
- *Base Station*: typically connected to a wired network and is responsible for sending packets between wired network and wireless host in it's area 
- *Wireless Link*: used to connect mobile devices to base station and could be used as a *backbone link*. Uses [[Multiple Access Protocols]] to coordinate link access. 
- *Infrastructure Mode*: base station connects mobiles into wired network and the mobile changes the base station providing connection into wired network 
- *Ad Hoc Mode*: No base stations and nodes can only transmit to other nodes within link coverage. Nodes organize themselves into a network and route among themselves.
